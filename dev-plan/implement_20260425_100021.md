# implement_20260425_100021.md

작성 일시: `2026-04-25 10:00:21 KST`

이 문서는 Legal Graph Chat MVP 이후 남은 후속 범위를 실제 구현 가능한 단위로 고정하고, 병렬 에이전트 작업이 충돌하지 않도록 경계와 병합 순서를 정의한다.

## 개발 목적
- 기존 `legalize-kr` 그래프 탐색 MVP에 남은 후속 항목을 안전하게 추가한다.
- LLM 답변 생성은 법률 자문이 아니라 source-grounded graph explanation으로 제한한다.
- `data/precedent-kr` 판례 corpus는 read-only 검색/미리보기/교차탐색 수준으로 통합한다.
- 배포/인증/권한은 local-first 기본값을 유지하면서 환경변수 기반 hardening scaffold를 제공한다.
- 실제 사용자 검증은 제품 내 feedback/test checklist와 문서로 연결한다.

## 개발 범위
- Backend API 추가/보강:
  - `/answer`: source-grounded 답변 DTO. 기본은 deterministic extractive answer, LLM provider는 disabled-by-default scaffold.
  - `/precedents/health`, `/precedents/search`, `/precedents/source`: `data/precedent-kr` read-only 검색과 안전 source viewer.
  - 환경변수 기반 local security settings: allowed origins, source viewer enable flag, precedent root.
- Frontend UI 추가/보강:
  - Chat 결과에 “source-grounded answer” 패널 또는 action 추가.
  - `Precedents` workspace tab: 판례 검색, 결과 목록, source preview, 법령 그래프 질문으로 전환.
  - Verify/User Testing 영역에 법률 자문 오해 방지 checklist와 feedback capture UX 추가.
- Infra/docs:
  - `.env.example`, 실행/배포 주의사항, local-only security guide.
  - plan 체크박스와 README 갱신.

## 제외 범위
- 실제 법률 자문 제공, 승소 가능성/법적 판단/행동 권고 생성은 제외한다.
- 외부 LLM API 호출의 기본 활성화는 제외한다. API key가 없는 환경에서도 테스트가 통과해야 한다.
- 판례 corpus를 `graph.json` 원본에 병합하거나 대형 raw payload를 브라우저에 직접 내려보내는 것은 제외한다.
- 사용자 계정/DB 기반 인증 시스템, 운영 배포, 멀티테넌시 구현은 제외한다.
- `data/legalize-kr/`, `data/precedent-kr/` 원본 corpus 파일 커밋은 제외한다.

## 문서 기반 제약 사항
- browser는 raw `graph.json` 또는 대형 판례 corpus를 직접 fetch하지 않는다.
- source viewer는 whitelist/read-only/path traversal 방지 원칙을 유지한다.
- API는 slim DTO를 반환하고 timeout/limit/cache/error shape를 유지한다.
- 법률 관련 문구는 항상 “그래프/판례 문서 탐색”으로 표현하고 법률 자문으로 오해될 표현을 금지한다.
- 모든 신규 기능은 API contract, frontend type, README, 테스트를 함께 갱신한다.
