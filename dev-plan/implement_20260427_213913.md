## 개발 목적
- `precedent-kr` Full 3D edge tile을 JSON 대신 binary payload로 받아 네트워크 크기와 main thread JSON parse 부담을 줄인다.
- Binary edge tile decode를 WebWorker에서 수행하고, 기존 StaticBufferGraph payload에 안전하게 병합한다.
- 기존 JSON edge tile 경로는 fallback으로 유지한다.

## 개발 범위
- Backend에 `/graph/full-3d/edge-tile/binary` endpoint를 추가한다.
- Binary edge tile format `graphify.edge-tile.binary.v1`을 정의한다.
- Frontend에 binary edge tile worker를 추가한다.
- App의 `Edge 25,000개 추가` 동작을 binary worker consumer 우선으로 변경한다.
- worker 미지원/endpoint 실패 시 JSON edge tile fallback을 유지한다.
- 문서와 테스트를 업데이트한다.

## 제외 범위
- 전체 full graph node payload의 binary consumer 전환.
- StaticBufferGraph가 raw typed array를 직접 유지하는 대규모 구조 변경.
- WebGPU renderer.
- 자동 전체 761k edge prefetch.
- backend edge tile disk cache.

## 최종 결과 요약
- Backend binary edge tile endpoint `/graph/full-3d/edge-tile/binary`를 추가했다.
- Binary format은 `GF3E\x01` magic, JSON header, uint32 edge source/target node index, uint8 LOD layer code로 구성된다.
- Frontend는 `edgeTileBinaryWorker.ts`에서 binary tile을 fetch/decode하고, 실패 시 기존 JSON edge tile API로 fallback한다.
- 판례 Full 3D `Edge 25,000개 추가` 버튼은 binary worker decode 경로를 우선 사용한다.

## 잔여 리스크 / 후속 과제
- Worker는 decode 후 GraphEdgeDTO 객체로 변환해 main thread로 전달한다. 다음 단계는 renderer가 typed array edge buffer를 직접 받아 객체 생성을 더 줄이는 것이다.
- Full graph node payload는 아직 JSON 기반이다. 다음 단계는 `GF3D` full node binary consumer와 persistent worker state다.
