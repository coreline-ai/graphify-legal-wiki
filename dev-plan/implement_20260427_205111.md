## 개발 목적
- Legal Graph Chat GUI에서 `legalize-kr` 법령 그래프와 `precedent-kr` 판례 그래프를 사용자가 명시적으로 선택할 수 있게 한다.
- 선택된 그래프에 따라 health, 질문 검색, 답변, subgraph, community overview, full 3D, source viewer가 같은 컨텍스트로 동작하게 한다.
- 판례 그래프는 124k 노드/761k 엣지 규모이므로 기본 UI는 안전한 제한 payload를 유지한다.

## 개발 범위
- Backend에 그래프 카탈로그와 `graph` 선택 파라미터를 추가한다.
- `legalize-kr`, `precedent-kr` 각각의 `graphify-out/graph.json`, `run-summary.json`, `GRAPH_REPORT.md`를 같은 query service 계약으로 사용할 수 있게 한다.
- Frontend sidebar에 두 그래프 선택 GUI를 추가한다.
- 선택 전환 시 기존 결과/선택/소스/3D 상태를 안전하게 초기화하고 새 그래프 기준 health/suggested questions를 다시 로드한다.
- active graph를 모든 graph API 호출에 전달한다.
- full 3D는 판례 그래프에서 raw all-edge 직접 로드를 기본 차단하고 sampled/static safe overview로 제한한다.

## 제외 범위
- 판례 전용 고정밀 검색 인덱스 개선, pgvector/FTS 구현.
- 판례 citation resolver 추가 개선.
- backend binary payload/streaming/WebWorker parsing.
- 외부 LLM provider 동작 변경.
- 그래프 JSON 재생성.

## 문서 기반 제약 사항
- Browser는 raw `graph.json`을 직접 fetch하지 않는다.
- Full 3D Graph는 opt-in, lazy-loaded, 기본 safe mode를 유지한다.
- Source viewer는 backend 경로 검증을 통과한 read-only preview만 제공한다.
- UI 문구는 법률 자문이 아니라 source-grounded graph exploration임을 유지한다.
