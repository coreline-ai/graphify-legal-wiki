이 문서는 이번 개발의 범위를 고정하고, 구현이 목적 밖으로 확장되지 않도록 하기 위한 작업 문서다.

## 개발 목적
- Full 3D Graph의 기본 edge 표현을 `1,500 nodes + 10k~20k visible edges`로 개선한다.
- 항상 보이는 backbone edge, 선택 노드 focus edge overlay, raw 176k density background, edge opacity/strength slider를 구현한다.
- 성능 보호를 유지하면서 사용자가 연결 라인을 명확히 볼 수 있게 한다.

## 개발 범위
- Backend full graph edge selection을 community-aware / degree-weighted LOD 방식으로 개선한다.
- Graph edge DTO metadata에 edge LOD layer 정보를 추가한다.
- Frontend Full 3D 기본 safe payload를 10k~20k edge 범위로 상향한다.
- Static 3D renderer에서 background/context/focus edge를 분리해 opacity와 색상을 다르게 표시한다.
- 2D fallback에서도 edge layer/strength를 반영한다.
- Full 3D toolbar에 edge strength control을 추가한다.

## 제외 범위
- 전체 그래프 layout 알고리즘 재작성.
- graph.json 원본 파일 변경.
- 법령/판례 corpus 데이터 수정.
- 176k edge를 모두 진하게 그리는 모드.
- 배포/PR 생성.
