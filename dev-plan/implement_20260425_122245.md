# implement_20260425_122245.md

작성 일시: `2026-04-25 12:22:45 KST`

이 문서는 Legal Graph Chat의 Full 3D Graph가 9,001 nodes / 176,128 edges 규모에서 브라우저를 멈추는 문제를 1차 Safe Mode로 완화하기 위한 개발 범위를 고정한다.

## 개발 목적
- Full 3D Graph 진입 시 브라우저 freeze를 방지한다.
- 전체 raw all-edge 렌더링을 기본 UX에서 제거하고, bounded overview / focus / sampled all-edge로 단계화한다.
- backend payload 크기, frontend JSON parse/render 비용, force simulation 비용을 동시에 줄인다.
- 기존 Community Overview, 3D Subgraph, source-first/legal disclaimer 흐름은 유지한다.

## 개발 범위
- Backend `/graph/full-3d`에 safe query params 추가:
  - `node_limit`
  - `edge_limit`
  - `min_degree`
  - `community_id`
- Backend `full_graph_3d`는 params가 없으면 기존 호환 동작을 유지한다.
- Frontend Full 3D 호출은 기본적으로 bounded safe params를 사용한다.
- Frontend WebGL renderer에 large graph profile을 추가한다.
- Full 3D UI copy를 “raw all edge”가 아니라 “safe overview / bounded edge sample”로 변경한다.
- 자동/수동 테스트와 browser smoke로 freeze 방지 기준을 확인한다.

## 제외 범위
- custom Three.js BufferGeometry renderer 신규 개발은 제외한다.
- backend precomputed 3D layout cache/파일 저장은 이번 1차 범위에서 제외한다.
- 176k raw edges를 browser에서 무조건 렌더링하는 모드는 제품 기본 UX로 제공하지 않는다.
- DB/LLM/Codex auth proxy/precedent index는 수정하지 않는다.
- Full 3D mobile 전용 UX는 이번 범위에 포함하지 않는다.

## Root cause 요약
- `/graph/full-3d?edge_mode=all&confirm_all_edges=true`는 최대 176,128 edges를 frontend로 보낸다.
- `WebGLGraph`는 graphData 변환 후 `react-force-graph-3d` force simulation에 nodes/links를 한 번에 투입한다.
- large graph에서 node geometry, link force, particle, label/hover, physics cooldown이 겹쳐 main thread/GPU가 멈춘다.
- 따라서 렌더러 튜닝만으로는 부족하고 payload limiting + renderer large profile + UX guard가 함께 필요하다.
